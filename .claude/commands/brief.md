brief-planner 에이전트를 사용하여 다음 기능의 간략 구현 계획을 작성해줘:

$ARGUMENTS

계획 작성 전에 반드시:
1. docs/api-todo.md를 읽고 인자($ARGUMENTS)와 관련된 항목을 찾을 것. 해당 항목에 Request/Response Body, 참고사항 등이 정의되어 있으면 이를 계획에 반영할 것. API 경로가 없고 제목만 있는 항목은 code-implementation-rules 스킬의 RESTful URL 설계 규칙에 따라 Method + URL을 결정할 것
2. 관련 기존 코드를 읽고 프로젝트 패턴을 파악할 것
3. code-implementation-rules 스킬을 참조할 것
4. 코드 스니펫 없이 파일명/클래스명/메서드명 수준으로만 작성할 것
5. 완료된 계획은 docs/brief/{YYYYMM}/ 디렉토리에 파일로 저장할 것
