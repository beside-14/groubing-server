rest-docs-generator 에이전트를 사용하여 다음 API의 REST Docs 문서를 생성해줘:

$ARGUMENTS

작업 전에 반드시:
1. rest-docs-writing 스킬을 참조하여 Vocabulary 패턴과 테스트 컨벤션을 숙지할 것
2. 해당 API의 Controller를 분석하여 request/response 구조를 파악할 것
3. Vocabulary 파일에 필드 정의 함수를 작성하여 재사용 가능하게 할 것
4. AsciiDoc snippet을 생성하고 main.adoc에 연결할 것
5. 테스트를 실행하여 통과를 확인할 것
